# Upasana

A small, playful web project created as a sweet digital love note for someone truly special.

This project is a romantic Valentine-style page that turns a simple "Will you be my date?" into an interactive, heartwarming experience with teasing messages, date plan choices, background music, confetti, and a memory page.

## Project concept

Upasana is not just a website — it is a personal gesture. The page starts with a gentle invitation, then playfully nudges the user with teasing "No" clicks, silly gif reactions, and a final surprise when the answer is yes.

It is designed to feel:
- warm and affectionate
- playful and memorable
- personal and handcrafted
- simple enough to run anywhere

## Highlights

- Interactive proposal flow with a teasing yes/no button experience
- Animated GIF reactions as the user keeps clicking "No"
- A date-planning section with options like:
  - Chai date
  - Long walk
  - Dinner date
- Local storage to remember the selected plan
- Background music with toggle control
- Celebration page with confetti and a happy ending
- Personal photo section to make the moment feel real and special

## Tech stack

This project is built using plain web technologies:

- HTML
- CSS
- JavaScript

No framework or package installation is required.

## How to run locally

1. Clone the repository
2. Open the project folder in your browser, or serve it locally with:

```bash
python3 -m http.server 8000
```

3. Visit:

```text
http://localhost:8000
```
